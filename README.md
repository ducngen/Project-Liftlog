# LiftLog
LiftLog ist ein digitales Trainingstagebuch für das Krafttraining.
Viele Trainierende notieren ihre Gewichte und Wiederholungen auf Papier oder im Handy und verlieren dabei schnell den Überblick. Ziel des Projekts ist eine Web-App, in der man jeden Satz einfach erfassen kann: Übung, Gewicht, Wiederholungen und Datum. Daraus zeigt die App den eigenen Fortschritt, zum Beispiel neue Bestleistungen oder das Trainingsvolumen pro Woche. So sieht man auf einen Blick, ob man stärker wird.
